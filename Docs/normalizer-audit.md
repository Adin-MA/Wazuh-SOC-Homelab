# Clear Temporary Auditd Normalizer Log Service 
Command for using  Clear Temporary Auditd Normalizer Log Service 

---

## Enable service at boot
```bash
sudo systemctl enable clear-wazuh-temporary-auditd-normalizer-log.service
```

---

## Erase Temporary Auditd Normalizer Log service
```bash
sudo systemctl start clear-wazuh-temporary-auditd-normalizer-log.service
```

---

## Stop service
```bash
sudo systemctl stop auditd-normalizer 
```
